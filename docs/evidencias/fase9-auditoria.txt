Fase 9 — Auditoria de eventos (User events + Admin events)

Configuracion aplicada en realm turismo:

  eventsEnabled           = true
  eventsListeners         = [ "jboss-logging" ]
  eventsExpiration        = 2592000           (30 dias)
  enabledEventTypes       = [
      LOGIN, LOGIN_ERROR,
      LOGOUT, LOGOUT_ERROR,
      CODE_TO_TOKEN, CODE_TO_TOKEN_ERROR,
      REFRESH_TOKEN, REFRESH_TOKEN_ERROR,
      REGISTER, REGISTER_ERROR,
      IDENTITY_PROVIDER_LOGIN, IDENTITY_PROVIDER_LOGIN_ERROR,
      CLIENT_LOGIN, CLIENT_LOGIN_ERROR
    ]
  adminEventsEnabled      = true
  adminEventsDetailsEnabled = true

Verificacion:

  kcadm.sh get events -r turismo --query 'max=5'
  -> devuelve los 5 ultimos eventos (ver abajo).
